Device patches

Advanced and optional: community patches that change the device itself, listed read-only in the installer app's step 7.

Not for most people. A device patch changes the device itself (for example Akai's own MPC program), it is not a plugin. Read the guide first, back up your projects, and use it at your own risk. The installer app only lists these; running one is done by hand over SSH with the script shown, whose checksum you can verify.

Drive exec: run plugins from a noexec drive (an MPC/Force's SSD)

by timomacquis (adapted by sd88me)
device patchUntestedMITNo MPC restartUndo built in

Replaced by Auto exec (use that instead; this one is kept so it can still be uninstalled). UNTESTED on a device by this project. MPC cannot load a plugin from a drive mounted noexec: it is listed but only shows Load Plugin. This makes one folder of the drive (Synths) executable, through a small boot-time service; the drive itself stays noexec.

Auto exec: run plugins from any noexec drive, no setup

by sd88me (mount logic after timomacquis)
device patchMITNo MPC restartUndo built in

Recommended for a noexec drive. MPC cannot load a plugin from a drive mounted noexec (SSD, USB stick, SD card): it is listed but only shows Load Plugin. This makes the Synths folder of every noexec drive executable through a small boot-time service, with nothing to choose; the drives stay noexec. Tried on a Force with two USB sticks, a plugin loaded and survived a power cycle (not yet tried: an eject without its release command); 0.3.1 also starts after a reboot when an overlay is mounted on /usr (tried on a second Force, two reboots), and 0.3.2 finds drives with a space in the name. Apply updates an installed 0.3.0 or 0.3.1 in place. Replaces drive exec.

Works on
MPC OS Gen1 (mount probe on a Force, 2026-10-14) (armv7l)
Changes
/etc/auto-exec
/etc/systemd/system/auto-exec.timer
/usr/lib/systemd/system/auto-exec-bootstrap.service
/media/<each noexec drive>/Synths (an executable bind mount of the folder)
Backup
/data/mpc-vst-plugins/backups

Button remap: open screens from hardware buttons

by mmiroshnikov
device patchMITMPC restartsUndo built in

Remap hardware buttons on a standalone MPC or Force (an LD_PRELOAD shim: a button can become other buttons, a pad or a screen tap). Pick which remaps you want at install (Force: Mixer, Edit, Clip, Menu and Knobs options; the Mode Menu must be at its default layout for the ones that tap an icon). The author's hwremap was tried on an MPC Live (Hakai, MPC 3.9.1) and a Force (stock 3.9.0); this installer and its Force rules were run on one Force (MPC OS 3.x) on 2026-10-10. Not tried yet: uninstall and the MPC Live map on a device. It does not work together with MidiLoop / MockbaMod's input path.

Works on
MPC OS 3.9 (MPC Live with Hakai, and Force stock 3.9.0, as tried by the remap's author) (armv7l)

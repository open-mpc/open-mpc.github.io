OsTirusMPC

Virus TI Snow hardware emulation for Gen2 MPC standalone. Includes an Audio Send companion effect that routes audio into the synthesizer's input, reproducing the original hardware's audio input behavior. Requires the user's own compatible firmware; none is included.

Instruments (1)

  • OsTirusMPC: Virus TI Snow hardware emulation for Gen2 MPC standalone, running the user's own compatible firmware. Eight touch pages, Q-Link maps, USER A-D banks, and Single-patch SysEx/MIDI file exchange. No firmware is included.

Effects (1)

  • OsTirusMPC Audio Send: Optional companion effect for OsTirusMPC on Gen2 MPC standalone. Routes audio from any track or individual pad to the OsTirusMPC virtual audio input.
